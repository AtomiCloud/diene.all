# Frontend UX Check

Loop the checklist over EVERY piece of UI work — new page, changed component,
reviewed diff. It is timeless and mandatory; the dated visual pick and the app's
identity sit on top of it and never override it.

Follow the authoritative checklist, section by section, in
**[frontend-ux/](../../../docs/standards/frontend-ux/index.md)** (A state
placement, B validation and forms, C responsive and visual, D mobile ergonomics,
E feedback and loading, F error flow, G accessibility mechanics, H the vision
loop, I trend and identity conformance).

- Recurring jobs have a recipe: [UX patterns](../../../docs/standards/frontend-ux/patterns.md)
- Current visual pick: [frontend-ui-trend/](../../../docs/standards/frontend-ui-trend/index.md)
- Per-app palette, UI language, and voice: [identity](../../../docs/domain/identity.md)

Reach for `vision-loop` once the checklist passes — it is what closes the visual
half.
