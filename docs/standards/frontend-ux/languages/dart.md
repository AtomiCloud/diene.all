# Flutter variant

- Bind shareable state to `go_router` routes and query parameters.
- Persist drafts with `SharedPreferences` or the selected local database.
- Use `FormField` validation on change and preserve autofill hints.
- Prefer `SafeArea`, `LayoutBuilder`, `Wrap`, `Expanded`, and logical
  directional APIs; test at narrow widths in every shipped locale.
- Read `MediaQuery.disableAnimationsOf(context)` before animating.
- Use `AsyncButton`, `BottomSheetSelector`, `AmountInput`,
  `PersistentFormField`, `ProblemVisualizer`, and `SafeAreaShell` as the
  baseline implementations.
- Capture emulator screenshots for human or vision review; do not add golden
  screenshot tests.
