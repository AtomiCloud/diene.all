# Frontend UI trend

Current selection, dated 2026-07: clean solid controls with Vercel-like polish,
adapted to Material 3 rather than imitating a web component library.

- Use crisp borders, subtle depth, purposeful gradients, generous whitespace,
  and one restrained radius scale.
- Pair one expressive display face with one highly legible body face.
- Use a single icon family and consistent stroke weight.
- Keep motion subtle, eased, and roughly 100–200 ms; disable it for reduced
  motion.
- Give the identity palette a dominant role in both themes. Avoid default-grey
  templates, purple-on-white AI gradients, bubbly cards, and decorative emoji.

Replacing this trend requires changing this document; the timeless UX standard
and the product identity remain intact.
