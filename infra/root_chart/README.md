# diene-go-base

Minimal Helm surface for the Diene Go language base

Chart metadata (version, type, appVersion) is defined in
[`Chart.yaml`](Chart.yaml). Configurable values and their defaults are defined in
[`values.yaml`](values.yaml); render the effective manifests with
`task helm:root_chart:template` to see them applied. This file is generated by
`helm-docs` from [`README.md.gotmpl`](README.md.gotmpl) and must not be edited by
hand.
